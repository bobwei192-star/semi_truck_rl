# 半挂车倒车入库需求文档 (v2.0)

## 1. 需求概述

### 1.1 目标

控制 A2 半挂车从起点以**倒车、匀速、不停车**方式精确定位入目标库位。

| 约束 | 说明 |
|------|------|
| 行驶方向 | 仅倒车 (v < 0) |
| 速度 | 匀速倒车，-1.0 m/s 固定 |
| 停车限制 | 不允许速度为 0 |
| 碰线限制 | 车辆任何部位不得触碰实线边界 |
| 中途不停 | 入库过程中不得停车 |

### 1.2 场地参数

| 参数 | 值 |
|------|------|
| 道路中心 X | 56.0 m |
| 车道宽度 | 8.0 m (单车道) |
| 道路总宽 | 16.0 m |
| 左边界 (实线) | X = 48.0 m |
| 右边界 (实线) | X = 64.0 m |
| 道路范围 Y | [0, 70] m |
| SCALE | 20 px/m |

### 1.3 库位定义

库位位于道路右侧，由道路右边界和中心虚线界定。

| 参数 | 值 |
|------|------|
| 目标中心 X | 58.25 m |
| 目标中心 Y | 50.56 m |
| 库位 X 范围 | [56.0, 64.0] m |
| 库位 Y 范围 | [47.5, 66.0] m |
| 目标航向 | 指向目标方向 (自动计算) |

### 1.4 起点位置

| 参数 | 值 |
|------|------|
| 基准 X | 54.0 m (随机 ±2.0) |
| 基准 Y | 9.91 m (随机 ±1.0) |
| 基准航向 | 自动指向目标 (±0.1 rad) |
| 初始铰接角 | 0 (±0.05 rad) |

### 1.5 车辆参数

| 参数 | 值 | 说明 |
|------|------|------|
| truckWidth | 3.0 m | 车头宽度 |
| trailerWidth | 2.8 m | 挂车宽度 |
| truckWheelbase | 3.0 m | 车头轴距 |
| trailerWheelbase | 11.0 m | 挂车轴距 |
| truckMargin | 1.0 m | 车头边缘余量 |
| trailerMarginFront | 1.0 m | 挂车前部余量 |
| trailerMarginBack | 3.0 m | 挂车后部余量 |
| maxSteeringDeg | 35° | 最大转向角 |
| maxArticulationDeg | 90° | 最大铰接角 |
| 车辆总长 | 21 m | |

## 2. 运动学约束

### 2.1 转向速率限制

| 参数 | 值 |
|------|------|
| max_steering_rate | 60 °/s |
| 实现 | 一阶速率限制 |

### 2.2 Jackknife 限制

| 参数 | 值 |
|------|------|
| 触发阈值 | \|g_rad\| > 85° |
| 行为 | 回合立即终止 |

### 2.3 倒车发散

半挂车倒车是非线性不稳定系统。铰接角超过 15°~30° 后，即使固定方向盘也会自发增大。

---

## 3. 碰撞检测

### 3.1 OBB 矩形检测

检测 8 个角点（车头4角 + 挂车4角），每个矩形独立旋转。

### 3.2 分级碰撞

| 级别 | 检测条件 | 惩罚 | 终止 |
|------|----------|------|------|
| 软碰撞 | 角点距边界 < 0.3m | -2.0 | 否 |
| 硬碰撞 | 角点超出边界 | -200 | 是 |
| Jackknife | \|g\| > 85° | -500 | 是 |

### 3.3 安全裕度

| 裕度 | 值 |
|------|------|
| 软碰撞预警 | 0.3 m |
| 道路外终止 | 超出道路范围即终止 |

---

## 4. 成功判定

| 指标 | 容差 |
|------|------|
| 位置 X 误差 | < 0.5 m |
| 位置 Y 误差 | < 0.5 m |
| 朝向误差 | < 10° |
| 铰接角误差 | < 5° (挂车必须对齐) |

---

## 5. 状态空间

### 5.1 观测向量 (9维, 相对坐标)

| 维度 | 含义 | 范围 |
|------|------|------|
| 0 | rel_x = truck_x - goal_x | R |
| 1 | rel_y = truck_y - goal_y | R |
| 2 | cos(rel_heading) | [-1,1] |
| 3 | sin(rel_heading) | [-1,1] |
| 4 | cos(g_rad) | [-1,1] |
| 5 | sin(g_rad) | [-1,1] |
| 6 | v_mps | [-5,5] |
| 7 | g_rad | [-π/2,π/2] |
| 8 | steering_norm | [-1,1] |

### 5.2 目标向量 (4维)

| 维度 | 含义 |
|------|------|
| 0 | goal_x |
| 1 | goal_y |
| 2 | cos(goal_heading) |
| 3 | 0 (目标铰接角) |
